02 // PENALTY THRESHOLDS

Jon-Bot uses a custom infraction points system called Damages. Reaching specific damage numbers triggers automatic punishments.

AUTO-MUTE LEVEL

3 DAMAGES

Hitting 3 damages automatically mutes the member across text and voice channels.

AUTO-BAN LEVEL

25 DAMAGES

Hitting 25 damages triggers an instant automatic ban and logs the incident.
